# Версия 2 — статус относительно 0.2.20

Крупный план (Tauri 2, несколько квестов, атлас, graphic mode, главы, зоны, настройки) реализован в ветке 0.2.x. Ниже — сверка с CHANGELOG.

## Сделано

- Tauri 2, несколько квестов, SQLite / IndexedDB
- Атлас: таксономия «Мир», индексные категории, визуальный Markdown, JSON и Markdown export/import
- Связь атласа с квестом (NPC, локации, опциональные ссылки)
- Графический режим, диалоги NPC в модалке, номера ответов
- Главы на графе, marquee/Shift
- Зоны: контур, рамка; кисть/DnD/devtools исправлены в 0.2.1–0.2.10
- Настройки шрифта и тем (0.2.19)
- Надёжность: Save/Discard/Cancel при закрытии, восстановление `atlas-before-taxonomy-v1` (0.2.20)

## Идеи на потом (не долг)

Новые функции добавлять по мере реального использования приложения. Крупный распил глобального `project`/UI не планируется, пока сопровождение не упрётся в модульность.
