# Библиотека персонажей (справка)

Статус: **superseded атласом 0.2**. Общая библиотека NPC реализована через вкладку «Атлас мира» (статьи типа «Персонаж») и копирование в `project.characters`. Этот документ сохраняет прежний контракт memory-репозитория для тестов и совместимости модуля `character-library.js`.

`character-library.js` предоставляет `createMemoryRepository(initial)` и асинхронные методы:

- `list()` — копии всех записей;
- `get(id)` — копия записи либо `null`;
- `put({id, name, image})` — создать или обновить запись, вернуть копию;
- `remove(id)` — удалить запись, вернуть признак удаления.

`image` — встроенный PNG/JPEG/WebP; PNG и WebP сохраняют прозрачность. Проверка данных общая с редактором и HTML-экспортом. Адаптер в памяти не переживает перезапуск и не является UI общей библиотеки.

Для работы с персонажами мира используйте атлас: спрайты, краткое описание, добавление в квест и опциональные ссылки в тексте. Пример PNG: `assets/characters/test-wanderer.png`.
